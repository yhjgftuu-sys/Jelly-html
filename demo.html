How it behaves.

The button is a native link first. Everything animated is a transparent canvas layered inside it, and that canvas never receives a pointer event.

Scroll, resize the window, or tap on a touch screen. The effect follows the layout, pauses when off‑screen, and falls back to a plain black pill without JavaScript or when prefers-reduced-motion is on. Everything on this page outside the buttons (these fonts, the red link hover, the form) is the host site, and none of it is touched.
